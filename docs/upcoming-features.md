4. “What should I cook?”
This could be genuinely useful if done properly.
Something like:
Surprise Me
Pick a random recipe from your selected category.

Or:
I'm feeling lucky

Very small feature, but it solves the “I want to cook something but don't know what” problem.

ically, Surprise Me is a random recipe picker.
Example:
You have categories like:
- Chicken
- Beef
- Pasta
- Vegetarian
- Desserts
Instead of choosing a category and browsing, the user taps:
🎲 Surprise Me
Rapid Recipes randomly selects a recipe from your database and takes them straight to it.
You could make it slightly smarter
For example:
Surprise Me
Feeling stuck? Let us pick something for you.

Then:
🎲 Surprise Me
→ Chicken Alfredo
→ View Recipe
And they can tap Surprise Me Again if they don't fancy it.
The key benefit is solving “I want to cook something, but I don't know what.”
It's a small feature, though. I wouldn't put it ahead of recipe scaling or Cooking Mode if you're looking for features that substantially improve the app.
