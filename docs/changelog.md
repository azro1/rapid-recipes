# Changelog

## 26 September 2026

- Sustainability is in the side menu. It finds recipes for food you already have.
- Use Ingredients is for ingredients that have not been used yet.
- Use Leftovers is for food that has already been cooked. Recipes that cook that food from raw are left out.
- Recipes that use more of the selected items come first. You can add your own items. A long press removes one you added.
- A recipe opened from those results stays on that path. A spinner shows until the details are ready.

## 22 September 2026

- Search on a category's dish list filters dishes by name.
- Save on a recipe stores it on the phone. Favourites is in the side menu and opens that recipe. Save again removes it.
- The green bar keeps the back arrow and also shows the menu, so Favourites can be opened from a recipe.
- About Us body text is 17, Work Sans Light, line height 28.
- Help body text and the support email are 17.
- About Us and Help use 16px side padding, the same as dishes and recipe.
- Select a Category and category dishes use the same gap between the title and the support line.
